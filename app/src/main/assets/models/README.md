# ИИ-модели (пока пусто)

В этой папке будут лежать **файлы моделей** (например, `.tflite`, `.onnx`, `.ncnn`
или иные артефакты), которые C++-слой будет использовать для поиска дефектов ЛКП.

## Планируемая структура

```text
app/src/main/assets/models/
├── paint_defect_detector.tflite   // базовая модель детекции дефектов
├── labels.txt                     // соответствие индексов классам дефектов
└── README.md                      // версия модели, источник, метрики
```

Правила:

- бинарники моделей в git не коммитятся, если есть отдельный store — тут только README;
- версию модели фиксировать отдельно (например, в `model_version.txt`);
- загрузку файла из assets будет делать будущий C++/ИИ-слой, Kotlin-камера
  о моделях ничего не знает.

Kotlin-код для работы с моделью появится позже в:

```text
app/src/main/java/com/example/bigbrother/data/ai/
```
